# How to map onscreen controls
1. Open the game.
2. Swipe down twice to reveal the Notification Toggles
3. Longpress the "Keymapp" button
4. Tap one of the buttons so that it's "Blue" (selected).
5. Press the corresponding button on the handheld.
6. Repeat for the rest of the controls.
7. Tap **Save**.

You can create different configs for different apps using the **Config Manager** option.
